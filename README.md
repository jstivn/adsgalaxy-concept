# Adsgalaxy — концепт главной страницы

Концепт редизайна главной страницы adsgalaxy.ru. Тестовое задание.

## Что внутри
- Анимация открытия: звёзды закручиваются в галактику, заголовок проявляется по словам.
- Первый экран — галактика на canvas. При прокрутке трафик из четырёх каналов (Контекст, SEO, CPA, AI-поиск) стекается к центру и превращается в выручку.
- Услуги — плитки с живыми мини-графиками. Кейсы — горизонтальная лента с набегающими цифрами.
- Калькулятор прогноза, шаги работы с заливкой линии, форма (в концепте ничего не отправляет).
- Живой фон, стеклянная шапка, курсор-кружок и магнитные кнопки.
- Адаптив под телефон, учитывается настройка «уменьшить движение».

## Технически
Один файл index.html, без библиотек и сборки. Шрифты Unbounded и Manrope (Google Fonts).
Все цифры и кейсы взяты с текущего сайта adsgalaxy.ru.
